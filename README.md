# Windrose & Company — windroseandco.com

Built with [Astro](https://astro.build).

## Setup

```bash
npm install
npm run dev
```

## Before going live

1. Copy `.env.example` to `.env` and add your Formspree form ID
2. Drop your profile photo at `public/assets/profile.jpg`
3. Run `npm run build` and deploy `dist/` to Netlify / Vercel
